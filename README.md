# AURA — сайт салона красоты

Адаптивный многостраничный сайт салона красоты AURA. Здесь опубликована готовая статическая сборка: HTML, CSS, JavaScript, шрифты и изображения. Для просмотра сайта не нужны установка зависимостей и серверная часть.

**[Открыть сайт](https://zengord.github.io/beauty-salon/)** · [Посмотреть в портфолио](https://zengord.github.io/portfolio/)

## Что есть на сайте

- Главная страница с услугами, ценами, командой мастеров, отзывами и галереей работ.
- Адаптивная верстка для телефона, планшета и компьютера.
- Окно записи с выбором услуги и даты, проверкой полей и подготовкой SMS.
- Отдельные страницы [политики конфиденциальности](https://zengord.github.io/beauty-salon/privacy.html) и [пользовательского соглашения](https://zengord.github.io/beauty-salon/agreement.html).

Форма записи открывает приложение для отправки SMS с подготовленным текстом. Сообщение отправляет сам посетитель после подтверждения; серверной обработки заявок в этой сборке нет.

## Структура репозитория

```text
├── index.html          # Главная страница
├── privacy.html        # Политика конфиденциальности
├── agreement.html      # Пользовательское соглашение
├── css/                # Стили
├── js/                 # Скрипты
└── assets/             # Изображения и шрифты
```

Сайт собран из исходного проекта на FLS/Vite. Этот репозиторий содержит только готовые файлы из `dist`; исходные компоненты и конфигурация сборки сюда не входят.

## Запуск локально

Из корня репозитория запустите простой статический сервер:

```bash
python -m http.server 8000
```

Затем откройте [http://localhost:8000/](http://localhost:8000/). На Windows можно использовать `py -m http.server 8000`.
